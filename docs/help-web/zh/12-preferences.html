首选项到底影响什么#

首选项不是把软件里所有按钮列一遍，而是决定“下一次新建元素时，默认是什么样”。打开首选项能看到哪些项目不重要，重要的是改动之后，它会怎样影响接下来的操作。

首选项主要影响四类行为：新建元素的初始状态、自动保存和启动方式、素材库和网络来源、导出时的默认参数。它通常不会反过来修改已经存在于画布上的元素。

通用：自动保存、语言和界面#

“自动保存”控制软件是否在后台定时保存已经保存过路径的工程。它适合防止意外关闭，但不能替代手动保存。刚新建、还未保存过的工程没有保存路径，因此不会自动生成工程文件。

“自动保存间隔”决定后台保存的频率。间隔短更安全，但工程很大、素材很多时，频繁写盘可能造成短暂卡顿；间隔长更安静，但意外退出时可能损失更多修改。对多数项目，几分钟一次比较平衡。

“导出后打开文件夹”只影响导出完成后的行为，不影响导出质量。如果你经常需要检查导出文件，可以打开；如果希望导出后继续工作，可以关闭。

“语言”切换界面语言。工程内容、文件名和自定义文字不会被自动翻译。

“主题”和“强调色”只改变界面外观，不会改变导出视频的颜色。浅色主题适合明亮环境，深色主题适合长时间编辑。

“工具栏密度”影响工具栏按钮的标签显示。窗口较窄时，标签会自动缩短；紧凑模式适合小屏幕，但需要更熟悉图标。

默认值：只影响新元素#

“SVG 默认出现方式”和“图片默认出现方式”决定新导入素材第一次出现时使用哪种动画。它们不会批量修改工程里已有的元素。

如果你主要做图标和线稿，可以把 SVG 默认设为矢量描绘；如果你主要处理照片，图片默认设为淡化或位图描绘更合适。

“默认出现时长”“默认停留时长”“默认切换时长”决定新元素的初始时间。它们只是起点，仍然可以在时间轴上单独调整。

“默认背景色”决定新工程的画布底色。它不会改变已经存在的工程背景。

“文字默认字体”决定新建文字和粘贴文字时使用的字体。已有文字不会被批量替换。更换默认字体之前，先确认字体已经安装，并且授权适合你的使用场景。

启动：打开软件时先看到什么#

“导航页”适合先浏览最近工程再决定打开哪个。“新建工程”适合每天从空白开始。“打开上次工程”适合连续几天做同一个项目。“每次询问”适合同时处理多个项目。

启动行为只影响打开软件时进入哪个界面，不会自动修改工程内容。

库和素材：引用而不是复制#

“添加素材库”把一个本地文件夹加入素材库索引。它不会复制文件，也不会移动原文件。素材库文件夹被移动或删除后，索引会失效。

“加入 VideoScribe 素材库”会引用本机 VideoScribe 的 Caches 和 Favourites。它同样只建立引用，不修改 VideoScribe 的原始目录。

“网络来源”控制素材库搜索时查询哪些网站。关闭某个来源不会删除已经下载到本地的素材，也不会影响工程中已经使用的素材。如果某个来源经常超时，可以关闭它，减少等待。

AI：地址、模型和密钥#

“API 地址”是兼容 OpenAI Chat Completions 接口的服务地址。“模型”是服务商提供的模型名称。“API Key”是访问凭证。

这三项必须匹配同一个服务。地址正确但模型不存在，或者 Key 无效，都会导致生成失败。

“AI 生成的 SVG 默认加入 AI 素材库”决定生成结果是否自动保存到本机素材库。开启后方便复用，但会占用磁盘空间；关闭后仍然可以在本次生成结果中直接插入画布。

API Key 保存在本机配置中，不写入工程文件。不要把带 Key 的配置发给别人。使用 AI 时，提示词会发送到对应服务商，不要放入敏感信息。

导出：默认参数不是最终限制#

“默认分辨率”“默认帧率”“默认导出位置”和“自定义尺寸”决定导出对话框打开时的初始值。

它们不会强制每次导出都使用同一设置。你仍然可以在导出对话框里修改分辨率、帧率、文件名和位置。

把常用的分辨率和导出目录设为默认值，可以减少重复操作；但每次导出前仍然应该确认输出尺寸和文件名。

什么时候需要改首选项#

如果你发现自己每次新建元素都要手动改同一种出现方式，或者每次导出都要重新选择同一个目录，就可以去首选项设置默认值。

如果你只是偶尔做一次视频，保持默认值即可。默认值的意义是减少重复劳动，不是必须配置的项目。

进一步说明：首选项影响的是“默认行为”#

首选项不是一次性设置，它会影响新建元素、自动保存、导出和素材库的默认行为。

如果你经常制作同一种风格的视频，可以提前设置好默认出现方式、默认时长、默认背景色和默认字体。这样每次新建元素时，不需要重复调整。

如果你只是偶尔使用，保持默认值即可。默认值是为了减少重复操作，不是必须修改的项目。

默认出现方式的选择#

SVG 默认出现方式建议使用“矢量描绘”，因为 SVG 通常有可解析路径。图片默认出现方式建议使用“淡化”或“位图描绘”，取决于你更常用照片还是插画。

如果默认值不适合当前元素，可以在元素面板里单独修改。默认值只影响新元素，不会批量修改已有元素。

自动保存的建议#

自动保存的间隔要根据工程大小和电脑性能调整。

工程很大、素材很多时，过于频繁的自动保存可能造成短暂卡顿。可以适当延长间隔，并在关键操作后手动保存。

工程较小、修改频繁时，较短的间隔更安全。

启动行为#

“打开上次工程”适合连续几天做同一个项目。“每次询问”适合同时处理多个项目。“导航页”适合先浏览最近工程再决定。

启动行为不改变工程内容，只改变打开软件时看到什么。

网络来源开关#

网络素材搜索依赖外部服务。某个来源无法访问时，可以关闭它，避免每次搜索都等待超时。

关闭来源不会删除已经下载到本地的素材，也不会影响本地素材库。

AI 配置和隐私#

AI 配置保存在本机，API Key 不会写入工程文件。

使用 AI 生成时，提示词会发送到服务商。不要把客户资料、未公开产品信息、个人隐私写进提示词。

如果多人共用一台电脑，建议在使用后移除 API Key，或者使用独立的系统账户。

快捷键的使用建议#

最值得先记住的是保存、撤销、复制粘贴、预览和导出。

Ctrl+S 和 Ctrl+Shift+S 要区分：前者保存当前工程，后者另存为并可以选择格式。

Ctrl+E 导出视频，Ctrl+P 预览。 Ctrl+S 不是“生成视频”。

Ctrl+Z 撤销，Ctrl+Shift+Z 重做。图形编辑器有独立的撤销历史，画布上的撤销不会回退图形编辑器内部的操作。

主题和界面密度#

主题和强调色只影响界面显示，不影响导出视频。

工具栏密度影响按钮标签的显示方式。屏幕较小时，紧凑模式可以腾出更多画布空间。

如果觉得界面太拥挤，优先折叠右侧不常用的面板，而不是把整个界面缩得很小。
