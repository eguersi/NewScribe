9. 动画、时间轴和镜头#

出现方式#

NewScribe 支持多种出现方式：

  • 淡化
  • 移动
  • 放大
  • 旋转
  • 展开
  • 矢量描绘
  • 位图描绘
  • 图表展示
  • 打字机

描绘#

描绘可以分为矢量描绘和位图描绘。这是 NewScribe 最值得理解的一组区别。

矢量描绘：

  • 线条清晰，适合图标、线稿和矢量图形
  • 生成速度快慢取决于路径复杂度
  • 更适合可编辑的矢量素材

矢量描绘支持svg、形状等矢量元素，会同时读取 SVG 的路径和描边，按照真实路径顺序描绘。矢量描绘有一个只描边选项，若不选择此选项，则在完成所有路径描绘后，会继续对填充区域进行描绘，模拟白板绘画时候先描边再涂色的涂抹效果。若选择只描边，若选择，则仅仅沿着路径前进，不会再对填充区域进行描绘，而是直接出现。值得注意的是，如果你使用的是来自VideoScribe的svg素材，那建议勾选只描边，因为VideoScribe的svg素材通常已经包含了模拟涂色的路径。

位图描绘则是读取像素内容，生成涂抹或扫描轨迹。位图仅支持位图描绘。

位图描绘适合照片、纹理和没有路径的图片，更接近“用笔把整张图涂出来”的感觉

简单说：

想要“沿线条画出来”，用矢量描绘。
想要“把一张图片涂出来”，用位图描绘。

复合淡入#

除了“淡化”本身之外，其他出现方式都可以额外勾选“同时淡入”。

例如：

  • 放大 + 淡入
  • 移动 + 淡入
  • 旋转 + 淡入
  • 展开 + 淡入

这会让元素在移动、缩放或旋转的同时逐渐显现，而不是突然出现。

停留和消失#

每个元素都有：

  • 出现时长
  • 停留时长
  • 切换时长

如果启用了“消失”，还会出现消失时长和消失方式。消失可以选择淡化、移动、缩放、旋转等。

出现动画和消失动画是两套设置#

出现动画回答“元素怎么进入画面”，消失动画回答“元素怎么离开画面”。它们不是同一个动画倒放。

一个元素可以只设置出现，不设置消失；也可以先出现、停留，再在后续某个时间点消失。出现和消失的时长、方式分别控制，不要把它们理解成同一个开关。

消失动画最适合“短暂出现一下，然后很快消失”的元素，例如闪现的提示、临时强调、错误答案或装饰性图标。它不适合“已经展示了很久，最后想慢慢擦掉”的内容。长时间停留后再淡出，会同时留下旧内容和淡出过程，画面容易显得拖沓。

如果要在展示较久之后把内容擦掉、露出下面的背景，应该使用蒙版。蒙版可以只作用于特定元素，也可以覆盖之前的全部元素；它控制的是“遮挡范围”，而不是让元素整体透明度降低。这样更适合“先展示、再擦除”的叙事节奏，也更接近白板动画里擦掉旧内容的感觉。

消失动画的取舍#

淡化消失适合不需要强调离开的元素；移动消失适合把内容移出画面；缩放消失适合收回强调；旋转消失适合装饰性元素。

不要让所有元素都用同一种消失。适度的变化可以形成节奏，但变化太多会让画面显得杂乱。

时间轴上的顺序#

时间轴按顺序播放：

出现 → 停留 → 切换 → 下一个元素

如果元素启用了消失，消失会发生在它自己的停留结束之后，再进入切换。调整时间轴时，要同时看出现、停留和消失，避免下一个元素已经开始，上一个元素还在消失。

镜头#

每个元素可以固定自己的机位：

  • 中心点
  • 缩放比例

把机位固定下来，也可以理解为固定视角：它始终以这个位置和缩放来看这个元素。

元素出现时，镜头可以从上一个位置平滑移动过来。

如果希望画面保持不动，可以给元素固定镜头，或者使用统一的机位。

时间轴#

时间轴按顺序播放：

出现 → 停留 → 镜头移动 → 下一个元素

可以拖动卡片排序，双击卡片从该元素开始预览。

进一步说明：先决定“怎么出现”，再决定“停多久”#

很多动画看起来不自然，不是时长不够，而是出现方式与内容不匹配。

一个简单的图标，用淡化或缩放通常就够了；一条流程线，用矢量描绘更有“画出来”的感觉；一张照片，移动或位图描绘比单纯淡入更有内容感；一个标题，打字机或放大更适合强调。

出现方式决定“观众先看到什么”，停留时间决定“观众有多少时间理解”。两者要一起调。

各种出现方式的手感#

淡化最简单，适合大多数元素。它不会改变位置和大小，适合文字、图标、图片和背景装饰。

移动适合“从画面外进入”的内容。

放大适合强调重点。

旋转适合圆形、徽章、装饰和需要活泼感的元素。

展开适合图片、卡片、面板和标题条。它像是在揭开一个东西，而不是整体出现。

矢量描绘适合线稿、图标和流程图。它最有白板感，但对 SVG 路径质量敏感。

位图描绘适合照片和复杂图片。它更像涂开，而不是描线。

图表展示适合柱状图、折线图和饼图，会按图表类型逐步显示数据。

打字机适合文字和代码，但速度要适中。太快看不清，太慢会让观众等。

矢量描绘的“只描边”#

矢量描绘有一个“只描边”选项。

不勾选时，NewScribe 会先沿路径描边，再对填充区域进行涂抹或填充，模拟“先画轮廓，再涂色”。这适合大多数普通 SVG。

勾选时，只沿着路径描绘，不再额外对填充区域做涂抹。来自 VideoScribe 的 SVG 素材通常已经包含模拟涂色的路径，这时勾选“只描边”可以避免重复涂抹。

如果发现矢量描绘结束后又出现一层奇怪的填充，先检查这个选项。

复合淡入的用法#

除了淡化本身，其他动画都可以同时勾选“淡入”。

移动 + 淡入适合文字和卡片从侧面进入；放大 + 淡入适合强调重点；旋转 + 淡入适合装饰；展开 + 淡入适合面板。

复合淡入会让动画更柔和，但也可能让元素显得“不够干脆”。需要强烈节奏时，可以不勾选淡入。

时间轴不是越紧凑越好#

时间轴紧凑，视频看起来节奏快；时间轴太松，观众会觉得拖沓。

一个参考节奏是：短句或图标停留 1.5～2.5 秒，长句停留 3～5 秒，复杂图表停留 4～6 秒。镜头移动时间通常比停留短，避免镜头还在移动时观众已经开始读下一段。

这些只是起点，最终要根据内容和配音调整。

镜头固定的意义#

每个元素可以固定自己的机位。固定机位的意思是：这个元素出现时，镜头以这个位置和缩放来看画面。

如果不固定，镜头会从上一个元素的位置自动移动过来。对连续讲解这是自然的；对需要稳定展示的图表或文字，固定机位可以避免画面漂移。

固定机位不是关键帧动画。它只定义一个静态的观察位置，不会自动产生推拉镜头。

消失动画的选择#

消失可以选择淡化、移动、缩放、旋转等。

如果下一个元素马上出现，淡化通常最自然；如果内容要移出画面，使用移动；如果要收回强调，使用缩放；旋转适合装饰性元素。

不要让所有元素都用同一种消失方式。适度变化可以让画面更有节奏，但变化过多会显得杂乱。

时间轴的实际操作顺序#

建议先粗排，再细调。

先把所有元素按出现顺序排好，统一设置一个大概的出现和停留时间。然后从头预览，找出“太快”“太慢”“镜头移动太多”的地方。最后再逐个调整关键元素的时间。

如果一开始就逐帧微调，后面一旦插入新元素，之前的时间都要重排。粗排优先，细调在后。
