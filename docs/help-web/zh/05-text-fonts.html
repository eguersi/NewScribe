文字与字体

文字、竖排、打字机、字体选择、字体版权和 SVG 内部文字。

8. 文字、字体和 SVG 文字#

文字元素可以设置内容、字体、字号、颜色、粗体、斜体、下划线、删除线等。

文字有左/中/右三种对齐方式，可以选择竖排，文字同时支持使用打字机出现方式，即一个字符一个字符的展示。

字体选择#

点击字体输入框会显示本机已安装的字体。当前字体没有修改时显示完整列表；开始输入后会按输入内容筛选。选择字体后，按回车或点击确认按钮应用。

“应用到全部文字”会把当前字体应用到工程里的所有文字元素，适合统一字体和处理版权问题。

字体版权#

如果字体不在已知开源/可商用字体列表中，界面会显示版权提醒。

常见较安全的字体包括：

  • 思源黑体 / 思源宋体
  • Source Han Sans / Source Han Serif
  • 文泉驿 / WenQuanYi
  • 得意黑 / Smiley Sans
  • 字魂扁桃体
  • 更纱黑体 / Sarasa Gothic
  • 霞鹜 / LXGW
  • Noto 系列
  • Inter、Roboto、Open Sans、Lato、Fira Sans、IBM Plex、JetBrains Mono 等

这份列表只是提醒，不构成法律意见。正式商用前仍应确认字体授权。

SVG 文字#

如果 SVG 含有 text、tspan 或 textPath，右侧元素面板会出现字体分组。

可以使用 SVG 自带的字体或选择或输入本机字体。

可以点击“应用到全部”，将当前字体快速应用到含文字 SVG。

替换字体只修改 SVG 内部文字，不会修改图形路径，不会影响svg中嵌入的位图中的字体或者已经转化为 path 路径的字体。

如果接收分享工程的人没有安装对应字体，SVG 会使用后备字体显示。

进一步说明：文字是信息密度最高的元素#

文字出现得快，观众不一定读得完。一个长句子即使只停留两秒，也可能来不及阅读。制作讲解视频时，文字应该比平面设计里更短、更分段。

一个实用原则是：一屏只表达一个主要意思。长句拆成两三行，关键词单独加粗或换色。需要逐字出现时，使用打字机效果；需要强调整体出现时，使用淡化或移动。

文字的字号不仅要看电脑屏幕，也要看最终视频在手机上的显示大小。导出后最好在手机上预览一次，确认字幕和关键词仍然可读。

竖排文字的使用场景#

竖排适合中文标题、书名、诗句、传统风格画面和狭长区域。它不是简单地把横排文字旋转 90 度，而是字符从上到下排列，换行形成新的列。

使用竖排时要注意：

  • 元素宽度和高度要足够容纳多列
  • 字号过大时，列数会迅速增加
  • 对齐方式和普通文字不完全一样
  • 打字机效果会按字符顺序出现

如果竖排文字被裁切，先检查元素边框，而不是字体。

字体替换的实际影响#

在 NewScribe 里换字体，只改变文字元素的渲染。它不会自动把文字转成路径，也不会把字体文件嵌入工程。

因此，分享工程后，接收方需要安装相同字体，才能得到完全一致的排版。否则字体会回退到后备字体，可能出现：

  • 字宽变化
  • 换行位置变化
  • 文字溢出边框
  • 标点位置变化

如果工程需要长期归档或跨设备使用，建议：

  • 使用常见字体
  • 把关键标题转成图形或 SVG
  • 或者把文字转为路径后再使用

字体列表为什么只显示已安装字体#

字体选择器会检测当前系统已安装的字体。列表里没有某个字体，通常不是软件坏了，而是系统没有安装，或者字体名称与系统注册名称不一致。

如果确定已经安装，可以尝试输入完整的字体家族名，而不是文件名。例如字体文件叫 SourceHanSansSC-Regular.otf，系统里的家族名可能是 Source Han Sans SC。

SVG 文字和普通文字的区别#

普通文字是 NewScribe 自己绘制的文本对象，可以直接改内容、字号、颜色和字体。

SVG 文字是 SVG 文件内部的 text/tspan 元素。NewScribe 可以检测并替换字体，但不会把它变成普通文字对象，也不能直接编辑原文内容。

如果 SVG 文字使用了版权字体，替换字体是降低风险的一种方式。但如果文字已经被转成路径，字体替换不会生效，因为此时它已经是图形，不再是文字，因此在使用包含文字的SVG前请务必做好检查。

字体版权的现实建议#

开源字体列表是一个辅助工具，不是法律结论。真正商用前，应该确认：

  • 字体许可证是否允许商业使用
  • 是否允许嵌入视频
  • 是否要求署名
  • 是否允许修改
  • 你的使用地区是否适用该许可证

如果不确定，优先选择明确标注 SIL OFL、Apache 2.0 或公共领域的字体，并保留授权说明。

文字排版检查清单#

导出前可以快速检查：

  • 是否有错别字
  • 是否有文字超出元素边框
  • 是否有行距过紧或过松
  • 是否有字体回退导致换行变化
  • 竖排文字是否在正确方向
  • 打字机速度是否适合阅读
  • 手机尺寸下是否仍然清楚
