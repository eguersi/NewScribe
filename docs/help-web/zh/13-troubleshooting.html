21. 数据安全和故障处理#

备份#

保存时会保留上一版：

工程.nscribe.bak
工程.nspkg.bak

如果主文件损坏，打开时会尝试从 .bak 恢复。

工程打不开#

可以按顺序检查：

  1. 主文件是否存在
  2. .bak 是否存在
  3. .assets 是否还在
  4. 文件是否被其他程序占用
  5. 是否被移动到了其他位置

素材丢失#

把 .assets 文件夹放回工程旁边，或使用“重新定位”。

如果经常需要分享，建议保存为 .nspkg。

导出失败#

先查看导出日志。

日志里会记录：

  • 准备阶段
  • 音频阶段
  • 视频帧阶段
  • 编码器排空
  • 封装阶段

如果日志长时间没有更新，可能已经卡住。

画面和预览不一致#

编辑页面是静态的，预览和导出才会应用时间轴。

蒙版、镜头、出现动画、消失动画都应该以预览为准。

22. 常见问题#

为什么保存后没有 MP4？#

保存保存的是工程，不是视频。

要生成 MP4，请点击“导出视频”。

为什么别人打开我的工程缺素材？#

你发送的是 .nscribe，但没有同时发送 .assets 文件夹。

解决方法是使用 .nspkg 分享工程。

为什么 SVG 描绘只出现一部分？#

可能是 SVG 路径过于复杂，软件回退到了位图描绘。

可以尝试：

  • 用 Inkscape 简化 SVG
  • 删除不必要的隐藏路径
  • 换成位图描绘
  • 缩短出现时长，观察是否是性能问题

为什么文字或 SVG 字体显示不对？#

检查字体是否安装。

SVG 字体覆盖只保存字体名称，不包含字体文件；接收方需要安装相同字体。

为什么导出很慢？#

常见原因：

  • 视频很长
  • 分辨率很高
  • 图片尺寸很大
  • SVG 路径非常复杂
  • 蒙版和目标图层较多
  • 编码器性能有限

可以先降低分辨率或减少同时出现的元素做测试。

为什么手势位置不对？#

自定义手势需要正确设置笔尖。

在手势设置中点击“可视化取点”，直接点击图片上实际落笔的位置。

为什么 AI 生成失败？#

检查：

  • Base URL 是否正确
  • 模型名称是否存在
  • API Key 是否有效
  • 服务是否支持 OpenAI 兼容接口
  • 网络是否可用

网络素材无法下载？#

检查：

  • 该来源是否在首选项里启用
  • 网络是否可用
  • 素材是否已经下架
  • 来源网站是否限制下载

进一步说明：先保护文件，再排查软件#

遇到工程打不开、素材丢失或导出失败时，先不要反复覆盖保存。

第一步是把现有工程、.assets 文件夹、.bak 备份复制到一个安全位置。这样即使后续操作失败，原始数据还在。

第二步是确认文件路径。工程、素材和备份是否还在原来的位置？是否被移动到了其他文件夹？是否被 OneDrive 等同步工具改成了“仅在线”状态？

第三步才是尝试打开或恢复。不要在原始文件上反复试验，使用副本更安全。

工程文件损坏后的处理#

如果主文件损坏，先检查同目录是否有：

工程.nscribe.bak
工程.nspkg.bak

把备份复制一份，改名为原扩展名，再尝试打开。不要直接覆盖原始损坏文件，先保留现场。

如果备份也打不开，检查是不是整个文件夹被移动、同步冲突或磁盘错误。可以把工程和素材一起复制到另一个本地磁盘再试。

素材丢失的处理#

.nscribe 需要 .assets 文件夹。素材文件名通常由哈希值组成，不建议手动改名。

如果 .assets 还在，但工程提示丢失，检查工程和 .assets 是否在同一目录，且文件夹名称是否与工程名匹配。

如果素材被移动，使用“重新定位”重新指向文件。重新定位后会更新工程记录，不需要重新导入。

如果素材彻底丢失，只能重新导入替代文件。重新导入后，需要重新设置出现方式和位置。

导出卡住时#

先看日志最后一行。

如果日志还在持续增加，说明程序仍在工作，可以继续等待。如果连续几分钟完全没有变化，可能已经卡住。

可以尝试：

  • 降低导出分辨率
  • 减少同一时间段的元素
  • 简化复杂 SVG
  • 关闭其他占用显卡/内存的程序
  • 重新启动 NewScribe 后重试

不要在导出过程中强制删除正在写入的视频文件。

黑屏或画面异常#

如果预览正常但导出黑屏，先降低分辨率测试。高分辨率导出对显存和内存压力更大。

如果只有某个元素异常，检查该元素的素材格式、尺寸和出现方式。过大的图片、复杂的 SVG 或动态 SVG 都可能引发问题。

如果是整段黑屏，检查输出框、镜头和蒙版。所有元素都被蒙版覆盖时，画面也会显示为背景。

字体问题#

字体缺失不会让工程损坏，但会改变排版。

如果文字换行、宽度或位置发生变化，先确认字体是否安装。分享工程时，接收方也需要安装相同字体。

SVG 字体替换只改文字，不会把字体文件打包进去。需要完全一致时，考虑把关键文字转成图形。

性能问题的排查顺序#

先看工程规模：元素数量、素材大小、视频时长、分辨率。

再看素材：是否有超大图片、复杂 SVG、动态 SVG。

然后看动画：是否有大量蒙版、位图描绘、同时出现的元素。

最后看电脑：内存、显卡、磁盘空间。

不要一开始就归因于软件。大多数导出慢的问题，来自工程规模或素材复杂度。

记录问题的好习惯#

遇到问题时，记录：

  • 工程大概有多少元素
  • 视频多长
  • 导出分辨率
  • 卡在哪个阶段
  • 日志最后几行
  • 是否只在某个工程出现

这些信息比“导出失败”四个字更容易定位问题。
