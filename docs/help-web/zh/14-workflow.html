制作流程与术语

从脚本到成片的工作流、镜头拆分、导出前检查和常用术语。

23. 一个推荐的实际制作流程#

如果你要做一个 1 分钟左右的讲解视频，可以这样安排：

先写一段简短脚本，把它拆成几个段落。然后为每个段落准备一个核心画面，尽量使用 SVG 图标、简笔画或文字，而不是大量高分辨率照片。

在 NewScribe 中，先按段落建立元素，再统一调整出现方式和镜头。完成粗排后，从头预览一遍，重点检查：

  • 元素是否出现得太快
  • 镜头移动是否太频繁
  • 文字是否在手机上看得清
  • 蒙版是否遮住了不该遮的内容
  • 音频和画面是否对得上

确认后再导出。第一次可以先用 720p 或 1080p 做测试，确认没问题后再导出最终分辨率。

用 NewScribe 制作的第一个视频#

《佛山行（一）【临高启明第三卷12】》是用 NewScribe 制作的首个视频，可以在这里观看：

佛山行（一）【临高启明第三卷12】

需要说明的是，这个视频经过了后期剪辑。转场、字幕等部分效果不是 NewScribe 制作的；NewScribe 负责的是白板动画、矢量描绘、手势、镜头和基础画面。把它当作整体风格参考，而不是把视频里的所有效果都当成软件功能。

24. 术语表#

SVG
可缩放矢量图形，用路径和形状描述图像，放大不会模糊。

位图
由像素组成的图片，例如 PNG、JPG。

矢量描绘
读取 SVG 路径，沿着真实线条进行描绘。

位图描绘
根据图片像素生成涂抹轨迹。

机位
某个元素出现时镜头所在的位置和缩放。

蒙版
用于遮住、挖空或隐藏某个区域的元素。

合成淡入
在移动、缩放、旋转等动画之外，再叠加透明度渐变。

自定义手势
用户导入的手部图片，可以设置笔尖位置和大小。

分享工程
.nspkg 单文件工程，内部包含素材。

进一步说明：从脚本到成片的工作流#

一个稳定的制作流程，通常不是“打开软件就开始画”，而是先在软件外想清楚结构。

先用几句话写出这段视频要讲什么。然后把内容拆成若干镜头，每个镜头只表达一个意思。再为每个镜头准备素材：图标、图片、文字、图表或公式。

进入 NewScribe 后，先按镜头顺序放元素，不要一开始就精修位置。粗排完成后再统一调整出现方式、停留时间和镜头。

镜头拆分的原则#

一个镜头只承担一个信息任务。

如果一句话里有两个并列信息，可以拆成两个元素或两个镜头。如果一张图里有太多细节，可以放大局部，或者用蒙版逐步揭示。

镜头切换不要过于频繁。观众需要时间理解画面，频繁移动会打断阅读。

素材选择的原则#

能用 SVG 表达的内容，优先 SVG。需要真实照片或纹理时，再用位图。

图标和线条尽量统一风格。同一视频里混用线稿、扁平插画、3D 图标和照片，会让画面显得杂乱。

素材颜色尽量和整体配色一致。NewScribe 可以改图形颜色，但复杂位图的颜色不容易统一。

时间安排的建议#

先粗排，再细调。

粗排时给每个元素一个大致出现和停留时间，确保顺序正确。细调时再处理“这句话太快”“这个镜头停留不够”“这个转场太生硬”。

如果视频有配音，先确定配音节奏，再根据语音调整元素出现时间。没有配音时，可以用音乐节拍作为参考。

导出前的检查清单#

内容方面，确认没有错别字、没有缺素材、没有遮挡错误、没有字体回退导致的排版变化。

节奏方面，确认开头能抓住注意力，中段没有长时间静止，结尾有明确的收束。

技术方面，确认分辨率、帧率、音频、字幕和文件大小符合发布平台要求。

术语速查#

画布
编辑区域，可以自由缩放和平移。

输出框
最终视频拍到的范围。

机位
某个元素出现时镜头的位置和缩放。

出现方式
元素进入画面的动画，例如淡化、移动、描绘。

停留
元素出现后保持不动的时间。

切换
镜头移动到下一个元素的时间。

蒙版
用于遮住、挖空或隐藏区域的元素。

矢量描绘
沿 SVG 路径描线。

位图描绘
根据像素生成涂抹轨迹。

复合淡入
在移动、缩放、旋转等动画上叠加透明度变化。

分享工程
.nspkg 单文件工程，包含素材和自定义手势。

常见术语的直观理解#

把“机位”想成摄影师站在哪里、镜头拉多近。把“输出框”想成最终镜头拍到的那块区域。把“时间轴”想成导演的场记表。把“蒙版”想成一张可以挖洞的纸。

理解这些比喻之后，再看参数会更容易：出现方式是演员怎么入场，停留是演员站多久，切换是镜头怎么移过去，消失是演员怎么退场。
