开始使用

先理解 NewScribe 是什么、它不做什么，以及第一次使用时应该先完成哪几件事。

1. 初识NewScribe#

NewScribe是什么#

NewScribe是一个自由免费的白板动画制作工具。你可能在各种视频平台上，见过一类软件制作的模仿手绘视频，这些视频大多使用Sparkol VideoScribe制作。NewScribe就是一款受Sparkol VideoScribe启发的开源软件。

工作方式#

NewScribe 不是视频剪辑软件，NewScribe更像一个“可播放的工程编辑器”。你可以：

  1. 你把元素放到画布上。
  2. 每个元素有自己的出现方式、出现时长、停留时间和消失方式。
  3. 每个元素还可以拥有自己的镜头位置和缩放。
  4. 时间轴把这些元素串成一条动画。
  5. 预览确认后，导出为 MP4。

你可以使用NewScribe制作科普动画、商业展示动画、演示说明动画等。

你可以用NewScribe直接导出视频，然而，NewScribe并不支持剪辑，没法导入视频素材，裁剪视频片段、裁剪音频、添加字幕或转场等。如果需要这些效果，你需要视频剪辑软件对NewScribe导出的素材进行处理。

2. 快速开始#

新建工程后，最常用的流程是：

  1. 导入一张图片、SVG 或音频，或者添加文字。
  2. 在画布上调整位置、大小和旋转。
  3. 在右侧选择出现方式。
  4. 设置这个元素的镜头。
  5. 在底部时间轴调整停留和切换时间。
  6. 点击预览。
  7. 导出 MP4，或保存工程继续编辑。

如果只做一次练习，建议先用一张图片和一段文字完成一个 5 秒左右的短片。

进一步说明：NewScribe 适合做什么#

NewScribe 最适合“边讲边画”的内容。一个知识点先出现关键词，接着出现图标或示意图，镜头再移动到下一组内容，这种节奏比单纯堆叠图片更有讲解感。科普视频、产品功能说明、课程片段、流程介绍、书籍摘要，都是它比较擅长的场景。

它不适合承担完整剪辑工作。NewScribe 不能导入视频片段，不能裁剪时间轴上的视频，不能做多轨剪辑、字幕轨、转场特效或调色。需要这些能力时，可以把 NewScribe 当成“画面生成器”：先导出 MP4，再到视频剪辑软件里配音、加字幕、加转场和做最终输出。

这个边界很重要。把 NewScribe 当成剪辑软件使用，会不断遇到“为什么不能剪”“为什么不能加字幕”的疑问；把它当成白板动画生成器，工作流会清晰很多。

第一次打开时先做什么#

第一次打开时，不要急着导入大量素材。先建立一个只有两三个元素的小工程，确认自己理解以下四件事：

  • 画布上的蓝色框是最终输出范围，框外内容不会出现在视频里。
  • 右侧面板修改的是当前选中的元素，选中对象不同，面板内容会变化。
  • 时间轴决定元素出现的顺序和停留时间，而不是画布上的前后位置。
  • 保存得到的是工程文件，导出视频才会得到 MP4。

这四点理解之后，再处理真实项目会顺利很多。

一个 5 分钟练习#

新建工程，导入一个简单的 SVG 图标。在右侧把出现方式设为“矢量描绘”，出现时长设为 1.5 秒，停留设为 2 秒。按预览，观察手势如何沿着图标线条移动。

然后把同一个元素复制一份，放到右侧，把出现方式改成“位图描绘”。再次预览。你会看到矢量描绘更像“描线”，位图描绘更像“涂开”。这两种效果没有绝对好坏，取决于素材和你想表达的感觉。

最后把工程保存为 .nscribe，再另存为 .nspkg。打开文件所在位置，观察两种文件的差别：一个旁边有 .assets 文件夹，一个是单个文件。这个对比比看十遍说明更直观。

做长工程时的基本习惯#

先保存，再开始大改。NewScribe 有自动保存和 .bak 备份，但重要节点仍然值得手动保存一次，尤其是导入大量素材、调整完时间轴、准备导出之前。

工程越大，越要减少“把所有东西都塞进一个元素”的做法。一个复杂画面可以拆成几个元素，分别设置出现时间和镜头，后续修改会容易得多。

如果准备分享，尽量在工程完成度较高时再另存为 .nspkg。分享包会复制全部素材，频繁重新生成大包没有必要。

如果工程太大，建议你可以适当拆分成不同工程，双方使用一致的背景方便后期使用剪辑软件合成等。
