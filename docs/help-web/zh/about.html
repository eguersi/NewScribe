NewScribe · 关于

把想法，画成视频。

NewScribe 是一个本地优先的手绘白板动画工作台。它把图片、SVG、文字、图形、图表、公式、分子结构和音标放在同一张画布上，用确定性的镜头时间轴制作动画并导出 MP4。

打开帮助中心 English help

技术路线

桌面应用使用 Electron 的主进程和预加载层，界面使用 React。画布使用 Canvas 2D 做确定性逐帧渲染，状态管理使用 Zustand。

导出使用 WebCodecs 和 mp4-muxer 编码 H.264/AAC 并封装 MP4。公式由 MathJax 和 mhchem 渲染；分子结构由 RDKit WebAssembly 渲染；国际音标使用 Noto Sans。
