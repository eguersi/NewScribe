素材与 SVG

导入图片、GIF、音频和 SVG；理解矢量图、位图以及素材版权。

6. 导入图片、SVG 和音频#

图片#

NewScribe 支持 PNG、JPG/JPEG、WebP、GIF、BMP、AVIF 和 SVG。其中PNG、JPG/JPEG、WebP、GIF、BMP、AVIF 均为位图，SVG为矢量图。使用矢量图可以获得更好的动画效果。

导入后可以调整位置、大小、旋转、透明度、出现方式和镜头。

GIF 和动态 WebP 会保留动态帧，导出时按动画帧使用。当前版本尚不支持有动态效果的svg（如鹈鹕骑自行车），因为svg代码中的动画部分过于复杂。建议使用静态的svg，动态svg容易出现各种异常，如预览与显示不一致等等。

音频#

支持 MP3、WAV、M4A、AAC、OGG 和 FLAC。

可以导入背景音乐，调整音量、淡入淡出、循环方式和播放一次。目前仅支持最多两条音轨，暂时不支持裁剪、编辑音轨。

素材丢失#

.nscribe 工程引用旁边的 .assets 文件夹。素材被移动、改名或删除后，工程会显示警告和红色占位框，可以使用“重新定位”重新接回文件。

.nspkg 分享工程不依赖外部素材文件夹。

拖动和粘贴#

NewScribe支持在文件资源管理器中拖动导入各类素材，包括图片和背景音乐。

在Windows操作系统上，NewScribe支持解析lnk快捷方式，当拖入快捷方式时，若其指向的目标文件存在，就按快捷方式实际指向的素材导入；不会修改快捷方式本身。

你也可以通过粘贴导入素材，支持的类型包括图片、文字和svg代码。当你复制一段文字，在画布上粘贴时，软件会自动判断这属于文字还是SVG代码，若为svg代码，则粘贴为SVG元素。

7. SVG 入门：它是什么，为什么推荐#

SVG 是什么#

SVG 是“可缩放矢量图形”的英文缩写。

和 PNG、JPG 这类由像素组成的图片不同，SVG 用路径、曲线、形状和颜色描述图像。你可以把它理解成一份“画图指令”，而不是一张已经拍好的照片。

因此 SVG 有几个特点：

  • 放大不会变模糊
  • 文件通常比高分辨率 PNG 小
  • 线条和形状可以被程序读取
  • 可以精确改变描边、填充和字体
  • 很适合手绘动画中的描边和路径描绘

为什么手绘动画推荐 SVG#

NewScribe 的“矢量描绘”会读取 SVG 内部的路径，按照真实线条顺序进行描绘，涂抹完路径线条后会继续对填充区域进行涂抹，模拟先描边再涂色的效果。它看起来更像真的在用笔沿着轮廓画。

PNG 或 JPG 没有路径信息，只能根据像素内容生成涂抹轨迹，这就是“位图描绘”的工作方式。

所以：

  • 图标、线稿、简笔画、标志、地图、流程示意图：优先 SVG
  • 照片、纹理、复杂插画、扫描图片：PNG/JPG 更合适
  • 结构复杂到无法解析的 SVG：NewScribe 会自动改用位图描绘，保证还能正常出现

另外，如果你的SVG是在VideoScribe的素材库里找到的，那么它通常已经包含模拟涂色的路径。使用矢量描绘时建议勾选“只描边”，避免软件再对填充区域重复涂抹。

SVG 里面可能有什么#

常见元素包括：

  • path：路径，最常见的图形
  • rect、circle、ellipse、line、polygon：基本形状
  • text、tspan：文字
  • style：颜色、描边、字体等样式
  • g：分组

NewScribe 会检测 SVG 里的文字标签。含文字的 SVG 会在元素面板中出现字体分组，可以替换文字字体，避免原 SVG 使用了有版权风险的字体。

去哪里找 SVG#

NewScribe 的素材库已经内置了多个网络来源，如Openverse、Wikimedia Commons、UnDraw、Qiuwenbaike、Iconify等。

在库之外，也可以去这些网站寻找：openclipart.org、iconfont.cn、SVG Repo。这些网站由于没有可用的API，因此无法在库中搜索使用，需要你手动去网站上搜索素材下载。

无论从哪里下载，都建议先确认授权，如是否允许商业使用，是否需要署名，是否允许修改，是否允许再分发等，“免费下载”不等于“可以随便商用”。

用什么软件创作和编辑 SVG#

你可以手动绘制或更改SVG。常见的软件由Inkscape、Adobe Illustrator、Affinity Designer、Figma、Boxy SVG等。

如果你只是想换颜色、删掉不需要的元素、改文字，免费开源的自由软件 Inkscape 通常已经足够。

进一步说明：素材不是越清晰越好#

导入素材时，最重要的是“在当前镜头下看起来足够清楚”，而不是“分辨率越高越好”。

一张 6000×4000 的照片，在 NewScribe 里可能只占画面的一小块。导出时它会被缩放、采样和编码，文件体积和内存占用却远高于实际需要。尤其是位图描绘，需要读取像素并生成涂抹轨迹，过大的图片会显著拖慢编辑和导出。

一个实用的判断方法是：如果导出分辨率是 1920×1080，而某个元素在最终画面中最多占三分之一宽度，那么它的有效显示宽度大约只有 600 多像素。原图比这个尺寸大很多，通常不会带来明显收益。

素材准备清单#

在使用一张图片之前，可以先检查：

  • 它是否需要透明背景？需要时用 PNG 或 SVG。
  • 它是否会被镜头放大？会被放大时，优先使用高分辨率图片或 SVG。
  • 它是否需要矢量描绘？需要时优先使用 SVG。
  • 它是否包含不需要的背景、水印或杂物？先在外部编辑器里清理。
  • 它是否允许在你的使用场景中商用？确认授权。

素材准备得越干净，后面在 NewScribe 里需要修补的地方越少。

SVG 的简单编辑建议#

SVG 是文本格式，可以用文本编辑器打开，但不建议直接手改复杂的路径数据。

更安全的方式是用 Inkscape 或类似工具打开，然后做这些操作：

  • 删除不需要的图层和隐藏元素
  • 把分散的路径合并成更少的路径
  • 把描边转成路径，或者保留描边
  • 删除过小的碎片路径
  • 简化节点数量
  • 将文字转为路径，或保留文字以便替换字体
  • 设置合适的 viewBox

如果 SVG 打开后显示正常，但导入 NewScribe 后描绘很慢，通常是因为路径节点太多。简化路径往往比提高电脑性能更有效。

为什么有些 SVG 不能很好地描绘#

SVG 只是“矢量”的容器，不代表里面一定是简单的线条。一个 SVG 可能包含：

  • 成千上万个微小路径
  • 复杂的滤镜和渐变
  • 嵌入的位图
  • 外部字体
  • 声明式动画
  • 蒙版和裁剪路径

NewScribe 会尽量解析路径。如果路径过于复杂，或者无法稳定解析，它会退回到位图描绘。这样至少能显示内容，但描绘效果会更接近“涂开”，而不是“描线”。

如果你需要稳定的矢量描绘，尽量选择线条清晰、节点数量适中的 SVG。

动态 SVG 的限制#

NewScribe 目前不支持复杂的动态 SVG。带 SMIL 动画、CSS 动画或复杂脚本的 SVG，预览和导出时可能出现异常。

如果你需要动画效果，建议：

  • 使用静态 SVG
  • 在 NewScribe 里用出现、移动、缩放、旋转来制作动画
  • 或者把动态效果拆成多张静态图，按时间轴依次出现

网络素材的授权判断#

“开放版权”不等于“无条件使用”。下载前至少确认：

  • 授权类型是 CC0、CC BY、CC BY-SA，还是仅限个人使用
  • 是否需要署名，署名写在哪里
  • 是否允许修改
  • 是否允许商业使用
  • 是否允许再分发

如果素材会出现在商业视频中，建议保留来源页面、作者和授权说明，方便以后核查。

劣质矢量图和位图转矢量图#

尽管矢量图有诸多优点，但是请注意，不是每个SVG都是良好的SVG。例如，一些SVG可能仅仅是引用或内部包含位图，或者矢量化地很糟糕，这样的SVG无法呈现正确的矢量描绘效果。

也正因为如此，也不建议你将含有复杂内容的位图直接转化为矢量图使用。把位图通过简单的色彩识别或者自动描摹转成 SVG 并不会自动获得干净的线条。例如很多矢量化软件会把轻微的颜色抖动识别为不同色块，从而创造很多无意义的琐碎路径，看起来是矢量，实际上很难编辑，也不适合手绘描绘。

如果原始素材是位图，通常直接用位图描绘更自然。只有在你有原始矢量文件，或者愿意手动重绘时，才值得做矢量化。
