15. 素材库、VideoScribe 和网络素材#

素材库不只是一个本地文件夹，它可以把多个来源放在一起使用。

本地素材库#

可以添加电脑上的素材文件夹。

添加后可以：

  • 浏览缩略图
  • 按文件名搜索
  • 直接拖入画布
  • 打开文件位置

移除素材库只会移除引用，不会删除原文件夹或文件。

VideoScribe 素材库#

如果电脑上安装过 Sparkol VideoScribe，NewScribe 可以检测它的素材库。

检测到之后，可以把VideoScribe 的 Caches 分类和VideoScribe 的 Favourites加入 NewScribe 素材库。

这个操作只建立引用，不会复制、移动或修改 VideoScribe 的原文件。

也可以在“首选项 → 库和素材”中手动点击“加入 VideoScribe 素材库”。

网络素材搜索#

素材库的“网络”页签可以搜索开放版权素材。

当前来源包括Iconify、Openverse、Wikimedia Commons、UnDraw、求闻百科。每个来源可以在首选项或搜索页面单独开关。受限于API限制和网络环境，有时候其中的一些来源会变得不可用。

搜索到素材后，可以预览、查看来源信息，再决定是否保存到本地。

使用网络素材的注意事项#

网络素材的授权情况各不相同。保存和使用前请确认：是否允许商用、是否需要署名、是否允许修改、是否允许再分发等。不同的来源其授权协议通常不同，例如，Wikimedia Commons上的很多图片以CC-BY协议发布，此时你必须以合适的方式同时标注文件作者、来源和协议等。

软件素材库提供的是查找能力，不是授权保证。

16. AI 生成 SVG#

NewScribe 可以使用兼容 OpenAI 接口的 AI 服务生成 SVG 素材。

配置#

在“首选项 → AI”中配置：

  • Base URL
  • 模型名称
  • API Key

如果模型服务兼容 OpenAI 的 Chat Completions 接口，通常可以直接填写对应的地址和模型。

API Key 保存在本机配置中，不需要每次重新输入。

生成#

打开“素材库 → AI 生成”，输入提示词，例如：

一只戴眼镜的卡通猫，透明背景，黑白线稿，适合白板手绘

点击“生成 SVG”。

生成结果会显示在素材库中，可以：

  • 直接插入画布
  • 保存到 AI 素材库
  • 继续修改提示词重新生成

使用建议#

AI 生成的 SVG 不一定完全符合预期，建议：

  • 提示词明确说明“透明背景”“线稿”“单色”“适合矢量描绘”
  • 生成后检查路径是否过于复杂
  • 过复杂的 SVG 可能更适合位图描绘
  • 商用前确认模型服务的使用条款

除此之外，你也可以直接在网页版的AI对话中要求它生成SVG代码。你可以点击下载，也可以复制代码，然后粘贴到画布上，软件会自动识别。

进一步说明：素材库是“索引”，不是“复制”#

添加一个本地素材库，只是让 NewScribe 记住这个文件夹的位置。它不会把素材复制到工程里，也不会移动原文件。

因此，素材库文件夹被移动、改名或删除后，库里的缩略图会失效。工程里已经引用的素材是另一回事：它们会按工程自己的 .assets 记录查找。

如果删除了素材库引用，原文件夹和文件不会被删除。这个设计避免了“管理素材库时误删原始资料”。

VideoScribe 素材库的价值#

VideoScribe 的 Caches 和 Favourites 里通常沉淀了大量已经整理过的图标、插画和手绘元素。重新下载或重新分类很费时间。

NewScribe 检测到本机 VideoScribe 素材库后，可以建立引用，直接在自己的素材库里浏览这些文件。它只读取路径，不修改 VideoScribe 的目录结构。

如果自动检测没有找到，可以在“首选项 → 库和素材”里手动点击“加入 VideoScribe 素材库”。加入后如果发现路径不对，可以移除引用，再手动添加正确文件夹。

网络素材搜索的实际流程#

在素材库的“网络”页签输入关键词后，NewScribe 会同时查询已启用的来源。结果可能来自不同网站，风格和授权方式并不统一。

看到喜欢的素材，先看来源、作者和授权信息，再决定是否保存。不要只看缩略图。

保存到本地后，素材会成为普通图片或 SVG，可以像本地文件一样导入工程。

网络来源的特点#

Iconify 主要提供 SVG 图标，适合界面、流程和简洁符号。它的图标通常线条清晰，适合矢量描绘。

Openverse 聚合开放版权图片，适合照片和插画。不同结果的授权可能不同。

Wikimedia Commons 及求闻百科适合公共领域和自由许可的图片、图表、地图和历史素材。

UnDraw 主要提供现代风格的 SVG 插画，适合商务和产品说明。

每个来源都可能受网络环境影响。如果搜索没有结果，先确认来源是否启用，再检查网络。

AI 生成 SVG 的定位#

AI 生成适合“我脑子里有一个简单图形，但不想自己画”的场景。

它最适合图标、线稿、简笔画、单色插图、简单场景。它不适合精确的工程图、复杂文字排版、真实照片或需要严格品牌规范的内容。

生成结果是一个 SVG 文件，不是位图。它仍然需要经过 NewScribe 的路径解析，所以路径太复杂时，描绘效果可能不理想。

提示词怎么写#

好的提示词通常包含：

  • 主体是什么
  • 风格是什么
  • 是否需要透明背景
  • 是否需要单色/线稿
  • 是否需要适合矢量描绘
  • 不需要什么

例如：

一个简单的黑色线稿齿轮图标，透明背景，没有文字，线条均匀，适合白板手绘描绘

比“画一个齿轮”更容易得到可用结果。

如果你使用的不是NewScribe的AI生成页面，而是使用网页版AI，别忘了嘱咐他，生成的是SVG代码而不是图片。如果不注意上述情况，一些AI就会很容易错误理解你的意图，并且调用图片生成功能生成位图。

AI 配置注意事项#

AI 功能需要一个兼容 OpenAI Chat Completions 接口的服务。Base URL、模型名和 API Key 必须匹配。

API Key 保存在本机配置中。不要把 Key 写进工程文件，也不要把工程发给别人时附带 Key。

使用 AI 服务时，提示词会发送到对应服务商。不要在提示词里放入敏感信息、未公开的项目内容或个人资料。

AI 素材库#

如果启用了“AI 生成的 SVG 默认加入 AI 素材库”，生成结果会保存在本机 AI 素材库中。

你可以在素材库里再次找到它，而不必重新生成。长期项目可以按主题建立不同的 AI 素材库文件夹。

AI 素材库仍然是本地文件，不会自动同步到云端。

素材管理的建议#

按项目或主题建立素材库，而不是把所有图片都放在一个巨大文件夹里。素材越多，搜索和浏览越慢。

文件名尽量描述内容，例如 icon-cloud-upload.svg，而不是 image1.svg。这样在素材库搜索时更容易找到。

删除素材库引用前，确认工程已经不再依赖这些文件。工程引用和素材库引用是两套独立记录。
