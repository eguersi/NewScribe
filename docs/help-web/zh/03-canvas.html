4. 主界面#

NewScribe 的界面大致分为四个区域。

顶部是工具栏，放新建、打开、保存、导入素材、文字、图形、图表、预览、导出、首选项和帮助等入口。

中间是画布。画布中的蓝色边框表示最终视频会拍到的输出范围。

右侧是属性面板。它会根据当前选中的对象显示画布、元素、文字、动画、蒙版、音频等内容。

底部是时间轴。时间轴决定元素出现的先后顺序和每一段动画的时长。

NewScribe 的很多设置是围绕“当前选中的元素”展开的。如果你找不到某个选项，先确认自己是否选中了正确的元素。

5. 画布与元素操作#

缩放和平移#

鼠标滚轮可以缩放，拖动空白处可以平移。

常用快捷方式：

  • + / -：缩放
  • 方向键：平移
  • 空格 + 拖动：平移
  • Shift + 滚轮：左右平移
  • Ctrl + 滚轮：上下平移
  • Alt + 滚轮：快速切换元素

拖动到边缘时自动平移#

把一个元素拖到可视区域边缘时，视角会自动向那个方向慢慢移动。

越靠近边缘，移动速度越快。这样可以把元素拖到当前画面之外，而不需要先松手、再平移画布。

选择、缩放和旋转#

单击选择一个元素。按住 Ctrl 可以多选。

拖动四周控制点可以缩放，按住 Shift 可以保持比例。

拖动顶部圆点可以旋转，按住 Shift 会以 15° 为步进。

复制和粘贴#

选中文件后复制Ctrl+C，会使该元素进入剪切板

和 Ctrl+V 使用最近一次复制的内容。

右键菜单中的“复制一份”是独立操作：

  • 只复制右键点击的那个元素
  • 不读取外部剪贴板
  • 不写入内部剪贴板
  • 不会影响之后的普通粘贴

多选#

多选后，右侧面板会只显示可以共同修改的属性。某些属性会显示“多个值”，表示不同元素当前的值不一致。

进一步说明：把界面当成四个协作区域#

NewScribe 的界面不是四块互不相干的面板，而是一条连续的编辑流程。

顶部工具栏回答“我要做什么”：新建、导入、加文字、加图形、预览、导出。中间画布回答“它现在长什么样”：位置、大小、旋转、层级和输出范围。右侧属性回答“它怎么出现、怎么运动、有什么样式”。底部时间轴回答“它什么时候出现、停留多久、下一步是什么”。

当你找不到某个选项时，先不要急着翻遍所有菜单。先确认三件事：当前有没有选中元素、选中的是什么类型、当前在哪个标签页。很多“选项消失”只是因为选错了对象。

画布、输出框和镜头不是一回事#

画布是你自由摆放元素的工作区域，输出框是最终视频会拍到的范围。

元素可以放在输出框外面。它在编辑时看得见，不代表导出时一定入镜。镜头的中心点和缩放决定最终视频从哪里看、看多大。

如果一个元素“编辑时在，导出时不见”，先检查它是否在输出框里，再检查它的机位是否把它带出了画面。

选中、多选和批量修改#

单击选中一个元素，Ctrl 点击增加选择，Ctrl+A 全选。

多选后，右侧面板只显示可以共同修改的属性。比如多个文字可以一起改颜色和字体，但不同元素的宽度可能显示为“多个值”，此时输入一个数值会统一覆盖它们。

批量修改之前，建议先确认选中的元素范围。多选很容易把画布外的元素也选进来，尤其是全选之后。修改前看一眼时间轴，可以知道到底选中了哪些对象。

拖动边缘自动平移的使用场景#

这个功能在“把元素移到当前画面之外”时特别有用。比如你想让一个图标从画面左侧进入，可以先把它放在画面外，再设置从左向右的移动；但手动拖到画面外很麻烦，因为一到边缘就看不见了。

把元素拖到边缘，视角会自动跟随，你可以继续把它放到更远的位置。松手之后，画布会保持在新位置。此时再按预览，就能看到元素从画面外进入的效果。

自动平移只改变视角，不会改变元素的世界坐标。它不会自动创建关键帧，也不会改变元素的出现方式。

复制、粘贴和复制一份#

普通复制粘贴使用最近一次复制的内容。你可以从 NewScribe 内部复制元素，也可以从外部复制图片、文字、SVG代码或其他支持的内容。

“复制一份”是另一条独立路径。它只复制当前右键点击的元素，不读取外部剪贴板，也不会把内容写进内部剪贴板。因此，复制一份之后，按 Ctrl+V 粘贴的仍然是之前复制的内容，而不是这份副本。

界面空间的管理#

右侧面板和时间轴都可以占用不少空间。屏幕较小时，可以折叠不需要的面板，或者使用全屏模式。

工具栏在窗口变窄时会缩短标签，只保留图标。这不是功能缺失，而是为了给画布留出空间。把窗口拉宽，标签会重新出现。

如果你经常使用某个面板，可以保持它展开；不常用的面板折叠起来，画布会更清爽。

外观、背景和画布边界#

外观#

NewScribe 支持深色、浅色和跟随系统三种界面主题。主题色也可以切换，常见选择有琥珀、蓝色、薄荷、紫色和玫瑰色。工具栏密度可以调整，用来决定界面元素排得松一些还是紧一些。

这些设置只改变编辑器的外观，不会改变画布内容，也不会影响导出的视频。配色时不要让界面主题干扰对画面颜色的判断，尤其是做浅色背景或低对比度画面时，最好在预览里再确认一次。

背景#

画布背景可以使用纯色、纹理或图片。

背景图片可以拉伸铺满，也可以平铺；可以固定在画面中，也可以跟随镜头移动。固定背景在镜头移动时保持不动，适合做纸张、墙面或固定纹理；跟随镜头的背景会随画布一起移动，适合让背景成为画面空间的一部分。

背景不参与元素的描绘动画。如果希望背景本身也被“画出来”，应该把图片作为普通元素导入，而不是只设为背景。

画布、输出框和缩放#

编辑页面显示的是一个固定大小的画布，但画布边界不是元素的存在边界。元素可以放到画布外面，只要最终机位看得到，预览和导出仍会正常显示。

默认开启「首选项 → 外观 → 编辑器展示原画布大小之外的空间」。开启后，画布外区域也使用当前背景色和纹理，方便看清和编辑画布外的元素；关闭后，画布外恢复为编辑器的灰色工作区。

缩放大小要适中，过大或过小可能出现显示问题。

镜像和导出#

选中元素后可以在属性面板中水平翻转。镜像改变的是显示和导出结果，不会修改原始素材文件；对文字、公式等需要阅读的内容使用镜像前，要确认观众仍然能读懂。

部分元素可以单独导出为 SVG，尤其是形状、公式、分子结构和音标等矢量内容。具体以对应元素面板中的导出按钮为准。
