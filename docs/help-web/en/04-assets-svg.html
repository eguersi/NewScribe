Assets and SVG

Images, GIFs, audio and SVG; vector versus bitmap, SVG basics and asset licensing.

6. Importing images, SVG and audio#

NewScribe supports PNG, JPG/JPEG, WebP, GIF, BMP, AVIF and SVG. The first six are bitmaps; SVG is vector.

After importing, you can adjust position, size, rotation, opacity, appearance and camera.

GIF and animated WebP keep their frames. Animated SVG is not supported reliably; complex SVG animation can produce incorrect previews. Use a static SVG when possible.

Audio formats: MP3, WAV, M4A, AAC, OGG and FLAC. You can use two audio tracks, adjust volume, fades, loop or play once. Audio trimming and detailed audio editing are not available in NewScribe.

Drag, paste and shortcuts#

You can drag images and audio from the file manager into NewScribe. On Windows, .lnk shortcuts are resolved to their target assets.

You can also paste supported content. Text is detected automatically; if the clipboard contains SVG source code, it is inserted as an SVG element instead of plain text.

Missing assets#

A local .nscribe project references its .assets folder. If a file is moved, renamed or deleted, NewScribe shows a warning and a red placeholder. Use Relink to reconnect the file. A .nspkg project does not depend on an external assets folder.

7. SVG basics#

SVG stands for Scalable Vector Graphics. It describes paths, shapes and colours instead of a pixel grid, so it stays sharp when scaled.

SVG is useful for hand-drawn animation because NewScribe can read its paths and trace them with a hand. It is a good choice for icons, line art, diagrams, logos and simple illustrations.

What is inside an SVG#

  • path: the most common shape format
  • rect, circle, ellipse, line, polygon: basic shapes
  • text, tspan: text
  • style: colours, strokes and fonts
  • g: groups

If an SVG contains text, NewScribe can replace its font in the element panel. This changes the text styling, not the shape paths.

Where to find SVG#

The built-in library searches Openverse, Wikimedia Commons, UnDraw, Qiuwenbaike and Iconify. Outside NewScribe, try openclipart.org, iconfont.cn and SVG Repo. These sites require manual browsing and downloading because they do not provide a library API.

Always check the licence: commercial use, attribution, modification and redistribution. “Free download” does not mean “free for any commercial use”.

Editing SVG#

You can edit SVG in Inkscape, Adobe Illustrator, Affinity Designer, Figma or Boxy SVG. Inkscape is free and is usually enough for changing colours, deleting unwanted elements and editing text.

Do not automatically trace a complex bitmap into SVG and expect clean paths. Tracing often produces many tiny, meaningless paths that are hard to draw and edit. Bitmap tracing is usually a poor substitute for a real vector source.

Why some SVG draw poorly#

A complex SVG may contain thousands of small paths, filters, gradients, embedded bitmaps, external fonts, masks or animation. NewScribe tries to parse the paths; if the structure is too complex, it falls back to bitmap drawing. That keeps the image visible, but the result looks more like painting than tracing.

For stable vector drawing, choose clean SVG with a reasonable number of nodes.
