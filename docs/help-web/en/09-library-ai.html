Library and AI

Local libraries, VideoScribe library, web asset search and AI-generated SVG.

15. Library, VideoScribe and web assets#

The library brings several sources into one place.

Local libraries#

Add any folder on your computer. You can browse thumbnails, search by filename, drag files into the canvas and open the file location.

Removing a library removes only the reference. It does not delete the folder or its files.

VideoScribe library#

If Sparkol VideoScribe is installed, NewScribe can detect its library. You can add the VideoScribe Caches categories and Favourites to the NewScribe library.

This creates references only. NewScribe does not copy, move or modify the original VideoScribe files. You can also use “Add VideoScribe library” from Preferences → Library & Assets.

Web asset search#

The Network tab searches open-licence sources. Current sources include Iconify, Openverse, Wikimedia Commons, UnDraw and Qiuwenbaike. Each source can be enabled or disabled independently.

Some sources may be unavailable because of API limits or network conditions. If a source times out, disable it in Preferences or in the search page.

Preview an asset and check its source information before saving. Downloading an asset does not grant a licence; it only gives you a local copy.

Licences#

Check whether the asset allows commercial use, requires attribution, allows modification and allows redistribution. Wikimedia Commons, for example, contains many CC BY images that require credit to the author, source and licence. Save the source page and author information when the asset will be used commercially.

The library is a search tool, not a licence guarantee.

16. AI-generated SVG#

NewScribe can generate SVG assets through an OpenAI-compatible service.

Configuration#

In Preferences → AI, set:

  • Base URL
  • Model
  • API key

The service must support an OpenAI Chat Completions-compatible API. The address, model and key must belong to the same service.

The API key is stored in local configuration. It is not written into project files. When you use AI generation, the prompt is sent to the provider; do not include confidential client material, private data or unreleased project information.

Generating#

Open Library → AI Generate and enter a prompt, for example:

A simple black-line cartoon cat with glasses, transparent background, no text, suitable for whiteboard vector drawing

Click Generate SVG. The result can be inserted into the canvas, saved to the AI library, or regenerated with a revised prompt.

Useful prompt details include “transparent background”, “line art”, “single colour”, “no text”, “simple paths” and “suitable for vector drawing”.

Limits#

AI-generated SVG is not guaranteed to be clean or accurate. Check path complexity, visual quality and the provider’s terms before commercial use. A very complex generated SVG may be better used with bitmap draw.
