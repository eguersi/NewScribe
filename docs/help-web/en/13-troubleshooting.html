Data safety and troubleshooting

Backup and recovery, missing assets, stuck exports, black frames, fonts and performance.

21. Data safety and recovery#

Save keeps the previous version as:

project.nscribe.bak
project.nspkg.bak

If the main file is damaged, opening it will try the backup automatically.

Protect the files first#

If a project will not open, first copy the project, .assets folder and .bak file to a safe place. Do not repeatedly overwrite the original while trying to recover it.

Then check:

  1. Does the project file exist?
  2. Does the .bak file exist?
  3. Is the .assets folder next to the project?
  4. Is another program locking the file?
  5. Has the folder been moved or synchronized by OneDrive or another tool?

Recovering a damaged project#

Keep the original damaged file. Copy the .bak file and rename the copy to the original extension, then try opening it.

If the backup is also damaged, copy the project and assets to another local drive and try again. Do not manually rename files inside .assets; their names are content-based.

Missing assets#

Put the .assets folder back next to the project, or use Relink. Relinking updates the project reference; it does not re-import the asset.

If the asset is permanently gone, import a replacement and set its position, appearance and camera again.

Export is stuck#

Look at the last line of the export log.

If it is still updating, the export may still be working. If there is no change for several minutes, it may be stuck.

Try:

  • lowering the resolution
  • reducing the number of elements in that time range
  • simplifying complex SVG
  • closing other GPU/memory-heavy programs
  • restarting NewScribe
  • ensuring enough disk space

Do not delete a file while it is being written.

Black frames or wrong frames#

If preview is correct but export is black, lower the resolution and test again. Large images, complex SVG, dynamic SVG and many masks increase memory and GPU pressure.

If only one element is wrong, inspect its asset, size, appearance mode and timeline position. If everything is black, check the output frame, camera and masks; a mask covering the whole frame leaves only the background.

Fonts look different#

A missing font changes line breaks, width and positioning. Check that the font is installed. A shared project does not contain font files. If exact typography is essential, convert critical text to graphics.

Performance checklist#

Check project size first, then assets, then animation complexity, then the computer. Large images, complex SVG, many masks and bitmap drawing are common costs. Do not assume the application alone is responsible.

22. FAQ#

Why is there no MP4 after saving?#

Saving creates an editable project. Use Export video to create an MP4.

Why does someone else see missing assets?#

You sent .nscribe without its .assets folder. Send .nspkg instead.

Why does an SVG draw only part of the image?#

The SVG may have very complex paths or unsupported structure, so NewScribe falls back to bitmap drawing. Simplify it in Inkscape, remove hidden or unnecessary paths, or use bitmap draw.

Why do fonts or SVG text look wrong?#

Check that the font is installed. SVG font overrides store the font name, not the font file. The recipient needs the same font.

Why is export slow?#

Long duration, high resolution, large images, complex paths, many masks and limited encoder performance all increase time. Test at a lower resolution first.

Why is the hand in the wrong place?#

Set the pen tip with visual pick on the custom hand image. Click the actual point where the pen meets the board.

Why did AI generation fail?#

Check the Base URL, model, API key, network connection and whether the service supports an OpenAI-compatible API.

Why can't I download a web asset?#

Check that the source is enabled, the network is available, the asset still exists and the site is not blocking downloads.
