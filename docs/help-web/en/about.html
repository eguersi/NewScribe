About

NewScribe · About

Turn an idea into a drawn video.

NewScribe is a local-first whiteboard animation studio. It places images, SVG, text, shapes, charts, formulas, molecules and phonetic symbols on one canvas, animates them with a deterministic camera timeline, and exports MP4.

Open the Help Center 中文帮助

Technology

The desktop app uses Electron main and preload processes; the interface uses React. The canvas uses Canvas 2D for deterministic frames, with Zustand.

Export uses WebCodecs and mp4-muxer to encode H.264/AAC and mux MP4. Formulas use MathJax and mhchem; molecules use RDKit WebAssembly; IPA uses Noto Sans.
