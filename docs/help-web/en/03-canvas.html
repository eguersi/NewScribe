4. Main interface#

NewScribe has four main areas:

  • The toolbar contains New, Open, Save, Import, Text, Shapes, Charts, Preview, Export, Preferences and Help.
  • The canvas is the editing area. The blue frame is the output frame.
  • The right panel changes according to the selected element.
  • The timeline at the bottom controls order and timing.

Most options apply to the currently selected element. If an option seems to be missing, check what is selected and which tab is open.

5. Canvas and element operations#

Zoom and pan#

Use the mouse wheel to zoom and drag empty canvas space to pan.

  • + / -: zoom
  • Arrow keys: pan
  • Space + drag: pan
  • Shift + wheel: horizontal pan
  • Ctrl + wheel: vertical pan
  • Alt + wheel: cycle elements

Edge auto-pan#

Drag an element near the edge of the visible area. The view starts panning in that direction, faster as you approach the edge. This lets you place an element far outside the current view without releasing the mouse.

Select, resize and rotate#

Click an element to select it. Ctrl-click adds to the selection. Ctrl+A selects all.

Drag the handles to resize. Hold Shift to keep proportions. Drag the top dot to rotate; Shift snaps to 15°.

Copy, paste and Duplicate#

Ctrl+C and Ctrl+V use the most recent clipboard content, including supported external content.

“Duplicate” in the context menu is independent of both clipboards. It copies only the element you right-clicked. It does not read or write the clipboard, so it will not affect the next paste.

Multi-selection#

When several elements are selected, the right panel shows only properties that can be changed together. Values that differ appear as “multiple values”; entering a value applies it to all selected elements.

Screenshots and interface icons#

The help site uses the same icons as the application, so the camera-frame icon, save icon, mask icon and file-type icons are easy to recognize while following the instructions.

Appearance, background and canvas bounds#

Appearance#

NewScribe supports dark, light and follow-system themes. The accent colour can also be changed (for example amber, blue, mint, violet or rose), and toolbar density controls how tightly the interface is packed.

These settings change only the editor. They do not change the project contents or the exported video. When choosing colours, check the preview again so the editor theme does not mislead you, especially on light backgrounds or low-contrast scenes.

Background#

The canvas background can be a solid colour, a texture or an image.

A background image can be stretched or tiled. It can be fixed to the frame or move with the camera. A fixed background stays still while the camera moves, which suits paper, a wall or a stable texture. A camera-following background moves with the canvas and becomes part of the scene space.

The background is not part of an element’s draw animation. If the background itself should be drawn, import the image as a normal element instead of only setting it as the background.

Canvas, output frame and zoom#

The editor shows a fixed-size canvas, but the canvas edge is not the limit of what can exist. Elements can be placed outside the canvas; as long as the final camera sees them, preview and export will still show them.

By default, Preferences → Appearance → Show space outside the original canvas is on. The area outside the canvas then uses the current background colour and texture, making off-canvas elements easier to see and edit. Turn it off to return the outside area to the grey editor workspace.

Keep zoom at a sensible level; zooming too far in or out may cause display problems.

Mirroring and export#

A selected element can be flipped horizontally in the inspector. Mirroring changes the display and export result, not the original asset file. Check readability before mirroring text or formulas.

Some elements can be exported separately as SVG, especially vector content such as shapes, formulas, molecules and IPA. Use the export control available in the element panel.
