Text and fonts

Text, vertical layout, typewriter, font selection, licensing and SVG text.

8. Text, fonts and SVG text#

Text elements support content, font, size, colour, bold, italic, underline, strikethrough and left/center/right alignment.

Text can be vertical, with characters stacked from top to bottom and new lines forming additional columns. The typewriter appearance reveals characters one by one.

Choosing a font#

Click the font field to show the fonts installed on this computer. The full list appears when the current value has not been edited; start typing to filter it. Press Enter or click the check button to apply a font.

“Apply to all text” applies the current font to every text element in the project. It is useful for consistent typography and for replacing a font with a safer alternative.

Font licensing#

NewScribe shows a warning when a font is not in its known open-source / commercially usable list. Examples of safer fonts include Source Han Sans, Source Han Serif, WenQuanYi, Smiley Sans, Zihun BianTaoTi, Sarasa Gothic, LXGW, Noto, Inter, Roboto, Open Sans, Lato, Fira Sans, IBM Plex and JetBrains Mono.

This list is guidance, not legal advice. Confirm the actual licence before commercial use.

SVG text#

If an SVG contains text, tspan or textPath, the element panel shows a font section. You can keep the SVG’s own font, choose a local font, or apply the font to all text-containing SVG files.

Changing the font only changes SVG text. It does not change shape paths, text embedded as a bitmap, or text already converted to paths.

A shared project does not contain font files. If the recipient does not have the font installed, the SVG uses a fallback font.

Fonts and layout#

Changing a font can change line breaks, text width and alignment. Check the result after changing fonts, especially with vertical text and small text boxes. Do not assume the same font name produces identical metrics on every computer.
