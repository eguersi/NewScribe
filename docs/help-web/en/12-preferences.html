Preferences and shortcuts

Defaults, autosave, startup, sources, AI configuration and shortcuts.

19. Preferences#

Preferences do not merely list buttons; they decide how the next action behaves. They mainly affect new elements, autosave, startup, the library and export defaults.

General#

Autosave controls whether NewScribe periodically saves a project that already has a file path. It is not a substitute for manual saving.

The autosave interval is a tradeoff: a short interval is safer but can cause brief pauses with large projects; a long interval is quieter but loses more work after a crash.

“Open folder after export” changes what happens after export. It does not change the video.

Language changes the interface language only; project content and filenames are not translated.

Theme, accent colour and toolbar density change the interface, not the exported video.

Defaults#

SVG default appearance and image default appearance apply to newly imported assets. They do not modify elements already on the canvas.

Default appearance, hold and switch durations are starting values for new elements. Default background colour affects new projects. Default text font affects new text and pasted text.

“Apply to all” in a text or SVG font section is a separate action; changing a default does not rewrite existing elements.

Startup#

Choose the Home screen, a new project, the last project, or ask each time. Startup choice does not change project content.

Library and assets#

Adding a library stores a reference to a folder; it does not copy files into the project. If the folder moves, the library reference becomes invalid.

“Add VideoScribe library” references VideoScribe’s Caches and Favourites without modifying them.

Network source switches control which sites are queried in the library. Disabling a source does not remove already downloaded assets or assets already used in a project.

AI#

Base URL, model and API key must match the same OpenAI-compatible service. The key is stored locally, not in the project.

“Add generated SVG to AI library” controls whether generated results are saved locally automatically.

Export#

Default resolution, frame rate, directory and custom size are initial values for the export dialog. They do not prevent you from changing settings for a particular export.

When to change preferences#

Change defaults when you repeat the same action often. If you only make an occasional video, leaving the defaults is fine.
